# Terminal_RussianRoulette
### This project is still in development

A simple Russian roulette game written in BASH, so you can play it non-stop, even in boring moments.

Also you can improve this script and make your own modifications

## Features:
- spinning barrel
- skip shoot
- characteristic action sounds (.mp3)

## To be added:
- ASCII graphics
- round counting
- scoring

## "Installation"
add x permission:

```chmod +x russRevol.sh ```

execute:

```./russRevol.sh ```

## Disclaimer
All ```revolver<X>.mp3``` files should be located in the same folder where ``` russRevol.sh``` is.
